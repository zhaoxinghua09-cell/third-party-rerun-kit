# 四层总账：每一层卡在哪，用命令跑出来的数

这一轮没加新能力，只做一件事：把发布前审查的**四层**分别用门禁脚本跑一遍，看真实读数。结论是四层全部 REFUSE，且缺口都能精确到一个字段。

## 一、四层读数（同一台公司机，2026-11-26）

| 层 | 脚本 | 读数 | 判定 |
|---|---|---|---|
| **S** 自证（11 门 S0–S11） | `admission_gate.py` | 19 件已发件中，**八条全成立 3 件（15.8%）**；其余 16 件不全 | REFUSE（exit 3） |
| **REQ** 准入八条 | 同上（逐条列 N/Y） | 每件 `1..8` 列几乎全 N；缺口字段一律是 `S10=None l3=False S11=None` | 见左 |
| **E** 外部证据（5 项） | `external_gate.py --all` | **36 条，PASS 0，REFUSE 36**；原因全是 E1/E2 缺证据文件 | REFUSE |
| **IO** 参与动作（八项） | `io_gate.py --all` | **9 条，PASS 0，REFUSE 9** | REFUSE |

四层里没有任何一项达到 PASS。这不是「部分通过」，是**零通过**。

## 二、每层的缺口定位到字段

### S / REQ：S1 做了，S10、S11、L3 全缺

`admission_gate.py` 输出的缺口列几乎每条都一样：

```
S1=PASS   S10=None   l3=False   S11=None
```

- **S1（引证核查）**：19 件里多数是 PASS——引用直达这一项是真做了。
- **S10（独立身份）**：全部 `None`，即没有「不是本人」的复核身份记录。
- **S11（终审）**：全部 `None`，即没有终审签署记录。
- **L3（授权原话）**：全部 `False`，即没有 L3 级别的书面授权留痕。

八条要求要全部成立才算准入，这四项一缺，八条就永远凑不齐——所以 19 件里只有 3 件成立，且这 3 件靠的是别的条目凑数。

### E：只缺两样，但两样都是「人」

```
E1 缺证据（missing file 外部门禁/external_ai/<id>.json）
E2 缺证据（missing file 外部门禁/outsider_run/<id>.json）
```

E1 的 `same_operator=false`、E2 的 `who` 非本人——这两条本人都无法满足。E1 交接包已备（`E1_handover_pack_20261126.md`），任何人用自己的 key 跑十分钟即可产出一条合规 E1 证据。

### IO：9 条全是硬伤，原因各异

| 条目 | 拒的原因（脚本原话） |
|---|---|
| DRAFT-01 / DRAFT-02 | `IO2 正文无缺口段`；`IO3` 2–3 条数字断言缺 `as of` 时点 |
| DRAFT-03 | `IO0 地址未取得列表归档授权（轴 b 未满足即发出）` |
| RECON-01 | `IO1 禁语命中 3 处（"唯一"×3）`；`IO3` 157 条数字断言缺 `as of` 时点 |
| GH-UIBCCORE / GH-AITB / GH-INTOTO | `E2 缺证据`；**`E5 实跑者是协作者，不是外人`** |

最后一行是这一轮最重要的一条**外部判定**：门禁自己把「我们跑 E5 的人」判成协作者，不是外人。这正好印证上一轮的自我纠正——E5 数据再全，也不能冒充 E2。

## 四、这一轮的真实产出

不是「又做了一层」，而是**把四层的缺口从「感觉差不多」变成「每条都有脚本读数与具体字段」**：

- 内容层（E5 三层证据）：61/61 实跑 → 33 件有断言 → **22/32 变异会变红（0.688，全量 33 件）**；
- 准入层：S/REQ 3/19、E 0/36、IO 0/9，全部 REFUSE；
- 唯一能自补的 E1 已做成交接包；其余都要外部的人。

结论一句话：**内容层已到本人能自证的极限；准入层零通过，且缺口全部是「不是我的人」或「不是我该签的字」。** 在此之前，这套东西的正确表述只能是「内部实测完成、外部准入未过」。
